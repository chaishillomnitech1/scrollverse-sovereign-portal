## Deployment

### Vercel Deployment

1. **Connect GitHub Repository**
   - Go to [Vercel](https://vercel.com)
   - Click "Import Project"
   - Select `scrollverse-sovereign-portal` repository

2. **Configure Environment Variables**
   ```
   VITE_APP_TITLE=ScrollVerse Sovereign Portal
   VITE_APP_VERSION=1.0.0
   ```

3. **Set Custom Domain**
   - Add your custom domain in Vercel dashboard
   - Configure DNS records

4. **Enable Automatic Deployments**
   - GitHub Actions will automatically deploy on push to `master`/`main`

### Manual Deployment

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel

# Deploy to production
vercel --prod
```
